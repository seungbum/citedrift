# CiteDrift

Checks whether the pages cited by an AI search answer still support it. Every statement–citation pair is judged twice,
against the page as it was when cited and against the page today, and gets one of six outcomes:
**still supported**, **content changed**, **uncertain**, **link lost**, **could not check**, **not supported when cited**.
Everything runs locally with open models on one consumer GPU (tested on an RTX 5070, 12 GB).

**Try it:** [public explorer](https://seungbum.github.io/citedrift/) · [74-second demo video](https://seungbum.github.io/citedrift/citedrift_demo.mp4)

- `app/` web app: static explorer of precomputed results (`app/static/`; `make site` copies it to `docs/` for GitHub Pages)
  and a local check mode (`app/server.py`).
- `src/citedrift/` the library: link state (`linkstate.py`), text extraction (`textutil.py`), support judge (`judge.py`),
  optional explainer (`explain.py`), end-to-end checker (`pipeline.py`).
- `src/` experiment scripts; `Makefile` maps every number in the paper to a script (see `make help` comments at the top).
- `results/` outputs of the experiments (scores, link states, summaries). No page bodies.
- `paper/` the 4-page demo paper; `paper/numbers.tex` is generated by `src/make_numbers.py`.

## Run the explorer or the checker

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -I app/server.py --no-models      # explorer only, no GPU
.venv/bin/python -I app/server.py                  # + check mode (MiniCheck-Flan-T5-Large, ~4 GB GPU)
.venv/bin/python -I app/server.py --explain        # + Qwen2.5-7B-Instruct 4-bit explanations (~10 GB GPU)
.venv/bin/python -I app/server.py --browser        # + one ordinary-browser visit for refused pages (Chrome, xvfb-run)
```
Open http://127.0.0.1:8765. Behind a TLS-intercepting proxy set `REQUESTS_CA_BUNDLE` to the system CA bundle.
If your own network answers some URLs with a web-filter notice page, list strings that identify that page in
`local/internal_markers.json` (`{"filter_markers": ["..."]}`) or `CITEDRIFT_FILTER_MARKERS="a|b"`, so that such pages
are reported as "could not check" rather than as lost.

## Data and licences

- Verifiability judgments of Liu, Zhang & Liang, *Evaluating Verifiability in Generative Search Engines*,
  Findings of EMNLP 2023 (MIT). Place the repository at `data/raw/liu2023/`.
- Judge: MiniCheck-Flan-T5-Large (Tang, Laban & Durrett, EMNLP 2024; weights MIT, inference procedure re-implemented
  from the Apache-2.0 reference code). Explainer: Qwen2.5-7B-Instruct (Apache-2.0).
- Baseline: urlhealth 0.1.0 (Rao, Wong & Callison-Burch 2026; MIT), called unchanged with added rate limiting.
- Current pages were fetched on 2026-10-15 and are kept locally only; they are not part of this repository.

## Fetching policy

One request per URL, at least 5 s between requests to the same host, identified user agent; sites that ask automated
clients not to fetch a page are not requested. Pages that refuse the plain client are opened once in an ordinary
browser; challenges are not solved, logins and paywalls are not bypassed.
