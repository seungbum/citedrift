What CiteDrift checks

An AI search answer is a list of statements, each pointing to one or more web pages. A citation can fail in two ways that a link checker cannot tell apart: the page can disappear, or the page can stay online while its text changes so that it no longer says what the answer claims. CiteDrift judges each statement–citation pair twice, against the page as it was when it was cited and against the page today, and puts the pair in one of six outcomes:

  • ✓ Still supported: supported then, page reachable, still supported now.
  • Δ Content changed: supported then, page reachable, the judge no longer finds support today and the passage that supported the statement then is no longer on the page.
  • ~ Uncertain: the page is reachable and the judge no longer finds support, but the second signal disagrees (the judge did not confirm support in 2023 either, or no evidence passage is available).
  • ✕ Link lost: supported then; the URL is dead, shows an error page, or redirects to a different document.
  • ? Could not check: the page could not be read from our network (bot wall, network filter, server or TLS error, time-out, empty page, or not requested because the site asks automated clients not to).
  • – Not fully supported then: the citation did not fully support the statement even when it was cited.

Pipeline

  1. Link state. One polite request per page (identified client, per-host spacing). Pages that refuse automated clients are opened once in an ordinary browser to separate bot walls from real loss. A redirect counts as a move when the new page still contains the old text (word 5-gram containment ≥ 0.3) or keeps its title.
  2. Text. Main content is extracted with Trafilatura; the full DOM text is kept as a fallback so that extraction misses are not mistaken for content changes.
  3. Support judge. MiniCheck-Flan-T5-Large scores the statement against every ~500-word chunk; the score is combined with word 4-gram overlap (weights fitted on the dev split). The threshold is fixed on dev.
  4. Explanation (optional). Qwen2.5-7B-Instruct in 4-bit reads the best passage and writes a one-sentence reason.

Data in this explorer

The 2,203 dev and test pairs of the verifiability judgments of Liu, Zhang & Liang (Findings of EMNLP 2023): answers from Bing Chat, NeevaAI, Perplexity and YouChat collected in February–March 2023, each pair labelled by an annotator together with the evidence sentences they copied from the page. We re-fetched every cited URL on 15 October 2026. "Then" in the explorer is the annotator's 2023 judgment; the judge scores are shown alongside.

What is not shown

Page bodies are not redistributed. The explorer shows only the annotator's evidence released with the dataset and the single closest sentence of the current page.
